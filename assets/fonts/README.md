# Bundled fonts

- Instrument Serif regular and italic: Google Fonts v5 Latin WOFF2 files, downloaded from the official Google Fonts stylesheet on 2026-10-11. License: `InstrumentSerif-OFL.txt`.
- Pretendard Variable 1.3.9: `orioncactus/pretendard` release, `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`. License: `OFL.txt`.

The page serves these files locally. Instrument Serif preserves the display typography; Pretendard provides Korean and Latin reading and utility text. The full Pretendard character set supports future Korean content edits.
